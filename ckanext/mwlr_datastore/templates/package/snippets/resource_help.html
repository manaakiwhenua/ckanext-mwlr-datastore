Guidance Tips

  • Recommended formats: CSV, JSON, XML, PDF, GeoJSON, Shapefile (ZIP), TIFF, PNG.
  • Maximum file size: 50 MB. For larger files, contact the Data Management Team before uploading.
  • Required metadata: Complete all required metadata fields before submitting.
  • Meaningful file names: Use clear, descriptive names that indicate the file content. Where useful, include the subject, location, date/year, or version. Avoid names such as data.csv, final.xlsx, or image1.tif.
    • Good: soil_samples_canterbury_2025.csv
    • Avoid: data.csv, IMG001.tif
  • File naming: Use consistent names with letters, numbers, underscores (_) or hyphens (-). Avoid spaces, special characters, very long names, and sensitive information.
  • Required metadata: Complete all required metadata fields before submitting.
  • Open formats: Use open, non-proprietary formats where possible to support reuse and long-term access.
  • README: Include a README file when additional information is needed to understand or use the data. For example:README.md or README.txt.
